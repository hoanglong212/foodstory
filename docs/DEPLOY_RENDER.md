# FoodStory free-cloud deployment

This repository includes a Render Blueprint for the Vue frontend and Node/Express backend. The backend remains MySQL-based, so the free reference layout uses an external Aiven for MySQL service.

## Services

- Frontend: Render Static Site (free)
- Backend: Render Web Service (free, sleeps after inactivity)
- Database: Aiven for MySQL Free (1 GB)

## 1. Create the MySQL service

1. Create an Aiven account and a Free MySQL service.
2. Open the service connection information and copy its MySQL service URI.
3. Keep the URI private. Do not place it in a file or Git commit.

The application accepts either `DATABASE_URL` or the individual `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, and `DB_NAME` values. The Render Blueprint uses `DATABASE_URL` and encrypted TLS mode.

## 2. Create the Render Blueprint

1. In Render, choose **New > Blueprint**.
2. Connect `https://github.com/hoanglong212/foodstory`.
3. Select branch `codex/render-deployment` and the root `render.yaml`.
4. Enter the prompted secret values:
   - `DATABASE_URL`: Aiven MySQL service URI.
   - `ADMIN_EMAIL`: private demo administrator email.
   - `ADMIN_PASSWORD`: unique value of at least 12 characters.

After the core deployment is healthy, optional provider keys such as `GROQ_API_KEY`, `GEMINI_API_KEY`, `GEOAPIFY_API_KEY`, `YOUTUBE_API_KEY`, and `GUARDIAN_API_KEY` can be added only to the backend service in the Render Dashboard. They are deliberately omitted from the Blueprint so they do not block the core deployment.

`JWT_SECRET` is generated by Render. Do not reuse or expose it.

## 3. First deployment

On the first backend start, `npm run start:production` creates the configured database schema and idempotently loads the recipe, restaurant, news, and optional administrator data. It records `production-bootstrap-v1`, so later cold starts and redeploys do not reset runtime content. Configured bootstrap users are safely refreshed so an administrator added after the first deploy is still created.

Verify:

- Backend health: `https://foodstory-api-cos30043-hoanglong212.onrender.com/api/health`
- Frontend: `https://foodstory-cos30043-hoanglong212.onrender.com`
- Health JSON reports `status: ok` and `database: connected`.
- Recipe listing/detail images load.
- Registration/login works.
- Admin login works only with the private credentials configured in Render.

## Free-tier limitations

- Render free web services sleep after 15 minutes without inbound traffic; the first request after sleep can take about one minute.
- Render local files are ephemeral. FoodStory stores persistent application records in external MySQL, not the service filesystem.
- The Aiven Free MySQL plan is intended for demos and small workloads and may be powered off after prolonged inactivity.
- Vision Auto and external-provider features remain disabled unless their provider keys and feature flags are intentionally configured.
