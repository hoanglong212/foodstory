# Portfolio capture checklist

`home.png` is a verified capture of the public FoodStory deployment on 23 August 2026.

Before the repository is linked from a CV, capture the remaining views while the API health endpoint reports `database: connected`:

1. `recipes.png` — populated recipe discovery with search and filters visible.
2. `recipe-detail.png` — hero image, ingredients, section navigation, ratings, and comments.
3. `food-map.png` — populated map with one selected place and its evidence/source state.
4. `admin.png` — moderation dashboard using non-sensitive demo data.

Use a consistent 16:9 desktop viewport, remove personal account details, and do not show API keys, environment variables, private email addresses, or browser extension UI.

Record a 60–90 second walkthrough covering recipe search, one recipe detail, Food Map, and one authenticated contribution/admin action. Add the final video URL to the root README only after verifying that it is publicly accessible.
